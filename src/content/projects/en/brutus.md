A symmetric encryption tool written for fun. It aims to be simple and at least nominally robust against frequency checks and dictionary attacks, while keeping the encrypted size equal to the original.

## Features

- 1:1 size ratio between plain and encrypted data
- Nominally robust against frequency analysis
- Text and file modes
- Library and CLI

> Named after Marcus Iunius Brutus. The real reason: Brutus should not be trusted.
